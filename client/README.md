# Dealwise — client

React 19 · Vite 8 · Tailwind 4 · TanStack Query. Setup, flows and architecture are in the
[root README](../README.md).

```bash
npm install
npm run dev        # http://localhost:5173 (expects the server on :4000)
npm run build      # type-check and production build
npm run lint       # oxlint
npm run test:e2e   # Playwright, drives the locally installed Chrome
```
